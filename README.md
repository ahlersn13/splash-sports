# Getting Started with Create React App

This project was bootstrapped with [Create React App](https://github.com/facebook/create-react-app).

## Available Scripts

In the project directory, you can run:

### `npm start` on the betting-lines to generate the React page

Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### open a second command line and run server.js on betting-lines/backend

This will create the comparison of lines

The app scrapes football lines from Office Football Pool / Splash Sports
It brings in lines from multiple sports books (DraftKings, Fanduel, etc.) and generates an average
It compares the OFP lines as a base and finds the greatest line movement against the average of the major sportsbook lines from the API
The index.html page prints out tables showing every game for the week as well as a table showing the 20 largest line movements for spread and total
